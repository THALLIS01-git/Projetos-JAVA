## 📌 Sobre o Repositório

Este diretório contém uma coleção de subprojetos criados com o objetivo de praticar conceitos fundamentais e avançados do ecossistema Java, tais como:
* ☕ Lógica de programação e estruturas de dados.
* 📦 Programação Orientada a Objetos (POO).
* 💾 Manipulação de arquivos e fluxos de dados.
* 🔌 Integração com APIs e boas práticas de código.

---

## 🛠️ Tecnologias e Ferramentas

* **Linguagem:** Java (JDK 17 ou superior)
* **IDE Recomendada:** IntelliJ IDEA, Eclipse ou VS Code (com a extensão Java Extension Pack)
* **Gerenciador de Dependências (se houver):** Maven / Gradle
